# Ly-enhancement-video-2 — بورتفوليو UX/UI

صفحة بورتفوليو لمصمم واجهات وتجربة مستخدم، مبنية بـ HTML/CSS/JS نظيف بدون أي مكتبات خارجية.

## المميزات
- 🎨 تصميم عصري (Glassmorphism + خلفية متوهجة + تدرّجات)
- 🌗 وضع ليلي/نهاري مع حفظ الاختيار
- 📱 متجاوب بالكامل (جوال / تابلت / ديسكتوب)
- ↔️ دعم RTL عربي
- ✨ حركات ظهور سلسة عند التمرير + micro-interactions
- ♿ احترام `prefers-reduced-motion` وتباين ألوان سليم

## الملفات
| الملف | الوصف |
|-------|-------|
| `index.html` | بنية الصفحة |
| `styles.css` | التصميم ونظام التوكنز |
| `script.js` | التفاعلات (الثيم، القائمة، الحركات) |
| `portfolio-preview.html` | نسخة ملف واحد للمعاينة السريعة |

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي:
\`\`\`bash
python3 -m http.server 8000
\`\`\`
